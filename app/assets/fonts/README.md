# Font

`pubspec.yaml` dichiara **Sora** (numeri e prezzi, cifre tabulari) e **Manrope** (tutto il
resto), come da pag. 4 del documento di progetto. I file `.ttf` **non sono inclusi** nel repo:
vanno scaricati e messi qui prima del primo `flutter run`.

File attesi:

- `Sora-Light.ttf` (300), `Sora-Regular.ttf` (400), `Sora-Medium.ttf` (500), `Sora-SemiBold.ttf` (600)
- `Manrope-Medium.ttf` (500), `Manrope-SemiBold.ttf` (600), `Manrope-Bold.ttf` (700), `Manrope-ExtraBold.ttf` (800)

Entrambi hanno licenza SIL Open Font License (gratuita) — coerente con la "regola di spesa".
Fonti: Google Fonts / repository ufficiali dei due caratteri.
